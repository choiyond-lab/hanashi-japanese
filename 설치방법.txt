하나시 일본어 — 휴대폰 홈 화면에 앱으로 설치하기

왜 이 폴더를 인터넷에 올려야 하나요?
  휴대폰에서 HTML 파일을 직접 열면(content:// 주소) 브라우저가 앱 설치를 허용하지 않아요.
  이 폴더를 HTTPS 주소에 올리면 Chrome이 "앱 설치"를 띄워 주고,
  설치 후에는 홈 화면 아이콘으로 브라우저 주소창 없이 바로 열리며, 인터넷이 없어도 학습할 수 있어요.

1) 폴더 올리기 — 방법 A: Netlify Drop (가장 쉬움, 무료)
   ① PC 브라우저에서 https://app.netlify.com/drop 접속 (무료 가입·로그인)
   ② 이 "하나시_앱배포" 폴더를 화면에 그대로 끌어다 놓기
   ③ 생성된 https://○○○.netlify.app 주소를 휴대폰으로 보내기
   ※ 로그인하지 않고 올리면 1시간 뒤 사라지니 꼭 로그인 후 올리세요.

   방법 B: GitHub Pages (무료, GitHub 계정 필요)
   ① GitHub에서 새 저장소(Repository) 만들기 → 이 폴더의 파일을 모두 업로드
   ② Settings → Pages → Branch: main / root 선택 → Save
   ③ 잠시 뒤 표시되는 https://아이디.github.io/저장소이름/ 주소 사용

2) 휴대폰에 설치
   안드로이드(Chrome): 주소 열기 → 화면의 "휴대폰에 설치" 버튼, 또는 ⋮ 메뉴 → "앱 설치"/"홈 화면에 추가"
   삼성 인터넷: ≡ 메뉴 → "현재 페이지 추가" → "홈 화면"
   아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
   설치 후 한 번 열어 상단에 "오프라인 학습 준비 완료"가 뜨면 인터넷 없이도 쓸 수 있어요.

3) 기존 학습 기록 옮기기
   기록은 "어디서 열었는지"마다 따로 저장돼요(파일 버전 ↔ 설치한 앱).
   이전 버전: 기록 탭 → 데이터 → "학습 기록 백업하기" → JSON 파일
   설치한 앱: 기록 탭 → 데이터 → "백업 불러오기" → 그 JSON 파일 선택

4) 앱을 고친 뒤 다시 올릴 때
   ① 이 폴더의 "배포폴더_업데이트.bat" 더블클릭 (index.html을 최신 앱 파일로 교체)
   ② sw.js 맨 위의 VERSION 숫자를 하나 올리기 (예: hanashi-v1 → hanashi-v2)
   ③ 같은 곳(Netlify 사이트의 Deploys 화면 / GitHub 저장소)에 폴더를 다시 올리기
   휴대폰 앱 상단에 "새 버전 준비됨"이 뜨면 눌러서 적용해요.

폴더 안 파일
   index.html            앱 본체 (하나시 일본어-휴대폰용.html 사본)
   hanashi-offline.html   파일로 내려받아 쓰는 버전 (같은 사본)
   manifest.webmanifest   앱 이름·아이콘 정보 (홈 화면 설치용)
   sw.js                  오프라인 저장
   icon-*.png             홈 화면 아이콘
